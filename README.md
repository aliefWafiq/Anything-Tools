# ANYTHING Tools

A versatile Command Line Interface (CLI) application built with Python. This project bundles several handy utilities into a single, easy-to-use tool to help streamline your daily tasks.

## Features

Here are the tools currently available and in development:

*   **Todo List**: Manage and track your daily tasks directly from the terminal.
*   **YouTube Downloader**: Easily download video and audio files from YouTube.
*   **Word to PDF Converter**: Convert `.docx` documents to PDF format seamlessly.
*   **PDF Summarizer**: Automatically extract key summaries from PDF documents *(Work In Progress)*.

## Getting Started

### Essential Commands

To start using the tools, you only need to know these primary commands:

**1. Initialize Configuration**
Run this command first to set up the basic configuration required by the application:
```bash
py -m anything init
```

**2. Open Main Menu**
Launch the interactive menu to navigate and use all the available features:
Bash

```bash
py -m anything menu
```
